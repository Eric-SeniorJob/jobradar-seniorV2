# JobRadar Senior V3

Prototype statique prêt à publier sur GitHub Pages.

### Publication
1. Créer un dépôt GitHub, par exemple `jobradar-senior`.
2. Décompresser cette archive et déposer `index.html`, `style.css` et `app.js` à la racine.
3. GitHub → Settings → Pages → Deploy from branch → `main` / root.
4. GitHub affichera l'URL publique.

### Important
Les annonces de cette V3 sont fictives et servent uniquement à tester l'interface. Les vraies annonces nécessiteront une source/API dont l'accès automatisé est autorisé.
