# JobRadar Senior — V4

Cette version propose des filtres de localisation, contrat, fonction et score minimum, ainsi que des options pour privilégier les profils senior et exclure les postes trop techniques.

**Les annonces de démonstration sont fictives. Aucune offre réelle n'est collectée dans cette version.**

## Mise à jour du dépôt `jobradar-seniorV2`
1. Décompressez le ZIP.
2. Dans GitHub, ouvrez le dépôt `jobradar-seniorV2` puis **Add file → Upload files**.
3. Déposez `index.html`, `style.css`, `app.js` et `README.md` à la racine, en remplaçant les versions existantes.
4. Cliquez sur **Commit changes**. GitHub Pages republiera le site.

## Pour connecter de vraies offres
Il faudra choisir une source/API dont les conditions autorisent l'accès et l'affichage. Ne placez jamais de clé API dans le JavaScript public ; selon la source, un backend ou un workflow planifié sera nécessaire.
